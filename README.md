# Causal Optimal-Transport Attention

Research code for **Causal Optimal-Transport Attention: Positional Priors and Length
Extrapolation**, by Ming Lian (Independent Researcher).

Source repository: [homw314159-spec/causal-ot-attention](https://github.com/homw314159-spec/causal-ot-attention).

The code includes prefix-consistent unbalanced attention, explicit positional biases,
fused Triton kernels, numerical checks, and the language-model training and evaluation
procedures used in the paper. The implementation is released under the MIT license.

## Quick start

Install Python 3.11 or later and [uv](https://docs.astral.sh/uv/getting-started/installation/).
From this repository's root:

```sh
uv sync --locked --all-packages
uv run pytest -m "not gpu and not slow"
uv run geoattn-train --config configs/smoke_lm.yaml train.device=cpu
```

The smoke run uses synthetic tokens and requires no dataset download or tracking account.
On Linux x86-64, the default environment uses CPU PyTorch. For CUDA training, use
`uv sync --locked --all-packages --no-group cpu --group gpu`.
Windows and Linux ARM64 use the pinned CUDA wheel index; consult
[reproduction](docs/reproduction.md) before changing the accelerator environment.

## Layout

| Path | Purpose |
| --- | --- |
| `packages/geoattn-core` | PyTorch attention operators and positional encodings |
| `packages/geoattn-kernels` | Fused causal OT kernels and reference fallbacks |
| `packages/geoattn-obs` | Attention probes and statistics |
| `packages/geoattn-train` | Causal GPT, token data pipeline, training and retrieval |
| `configs` | Model configurations, paper arms and reproduction recipes |
| `scripts` | Training recipes, evaluation, decision rules and mathematical probes |
| `docs/reproduction.md` | Data preparation, commands and expected artifacts |
| `docs/experiments.md` | Mapping between paper results, recipes and evaluation scripts |
| `docs/methods.md` | Operator semantics, tests and implementation scope |
| `docs/attribution.md` | Method references, dependencies and data licensing |

Training data, checkpoints, private development history and internal experiment reports
are not distributed. Scripts consume checkpoints generated by training or supplied by
the user. Published numerical results remain in the paper; this source release does not
claim to contain the original run artifacts.

## Run one paper arm

```sh
uv run python scripts/train_experiment.py 0001-confirm --arms rho0.5
```

This prints the commands. Add `--run` to train all three seeds of that arm. Training
requires the prepared dataset and substantial GPU time; see the reproduction guide.
All shipped configurations disable W&B and omit account identifiers. Local `config.yaml`,
`meta.json`, `data.json` and `metrics.jsonl` remain the canonical run records.
